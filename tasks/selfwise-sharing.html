passed failed · one square per hidden test, grouped by part of the feature: Friends, Receiving, Sharing, Update, Who sees · Configuration: a model, the harness it ran in, its effort and its method. A method is what the harness was given to work with: plugins, skills, instructions. With method none it is the harness as installed · Score: hidden tests passed over their total · Result: Passed when every hidden test passed and no existing check fails · Existing checks: the tests, the type check and the lint the repos had before; the count is of those that pass, and on a red one the pointer or a press shows which failed; a failing one makes the result Failed and leaves the score as it is · Subagents: how many the main agent started; each one's type, model and time are on the attempt's page · Cost: for Claude Code its own estimate at API prices (those trials ran on the subscription); for OpenCode the cost the harness reports for its calls to the model's provider · press an attempt's number for its page.

Public pages: the names of the hidden tests, why each failed, the code the agents wrote, the transcripts and the task's text are left out.
