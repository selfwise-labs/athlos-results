Configuration: a model, the harness it ran in, its effort and its method. A method is what the harness was given to work with: plugins, skills, instructions. With method none it is the harness as installed · Score: per task, hidden tests passed over their total, averaged over the attempts; then averaged over the tasks the configuration ran, each task counting once · Simple, Medium, Complex: the same over the tasks of that type (a task’s type is set before any run, from what the feature touches); n/a while no task of the type exists, – when the configuration ran none of them · Tasks run: of the 2 tasks below · Passed: every hidden test, and the repos’ existing checks (tests, type check, lint) still pass · Attempts: 3 per task and configuration · Cost: for Claude Code its own estimate at API prices (those trials ran on the subscription); for OpenCode the cost the harness reports for its calls to the model's provider.
